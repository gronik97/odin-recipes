Welcome to Odin Recipes, my very first project for The Odin Project!

What's This About?

This is a simple (but delicious) website where I share some of my favorite recipes.
The main goal was to practice basic HTML skills like:

- Creating multiple web pages and linking them together
- Structuring content with headings, paragraphs, and lists
- Adding some mouth-watering images
- Working with relative file paths

Features

A cozy homepage that links to several tasty recipes 🍝🍰🍳

Each recipe page includes:

- A short intro
- A neat list of ingredients
- Easy-to-follow cooking instructions

Built With

Just good old HTML5 (for now!)

Why I Built This

Practice makes perfect! This project helped me get comfortable with the basics of building websites. It’s a small but important step towards bigger and more complex projects.
